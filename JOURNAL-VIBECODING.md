## 1. Definisi Stack & Arsitektur

### Stack yang Digunakan

- React JS
- Vite
- CSS Murni
- JavaScript ES6
- ChatGPT dan VS Code AI Assistant

### Alasan Pemisahan Komponen

Saya menggunakan React karena memudahkan pembuatan antarmuka yang interaktif. Struktur project dipisahkan antara file JSX dan CSS agar kode lebih rapi dan mudah dikelola. Styling ditempatkan pada file App.css sedangkan logika aplikasi berada di App.jsx.

## 3. Log Problem Solving

### Deskripsi Error / Bug

Tampilan judul, ikon Al-Quran, dan angka penghitung saling bertumpukan sehingga antarmuka terlihat berantakan.

### Langkah Investigasi

Saya memeriksa struktur JSX dan CSS yang digunakan. Setelah dicek, beberapa elemen memiliki pengaturan posisi dan ukuran yang kurang tepat sehingga saling menimpa.

### Kolaborasi dengan AI

"Saya meminta AI membantu memperbaiki tata letak agar ikon, judul, angka penghitung, progress bar, dan tombol tersusun dengan rapi."

### Solusi Akhir

Saya memperbaiki pengaturan layout menggunakan Flexbox dan menyesuaikan margin serta ukuran elemen. Setelah diperbaiki, semua komponen tampil lebih teratur dan mudah dibaca.
